# Snap1280

Camera page that saves a JPEG whose longest side is at most 1280px. The preview frame uses the same aspect ratio as the photo that is saved.

## Layout

- `src/` — app source (`index.html`, `styles.css`, `app.js`, `photo.js`)
- `docs/` — built static site for GitHub Pages

```bash
node build.mjs
```

Built by grok.

Live site: https://makzan.github.io/snap1280/
